# **App Name**: DinnerTime

## Core Features:

- Meal Input: Input a set of meals.
- Weekly Planner: A user-friendly interface for assigning meals to days of the week.
- Export: Download the plan in a variety of formats.
- Smart Suggestion: AI-powered suggestions based on meals you've entered.
- Variation Generation: Suggest alterations to a selected meal based on its component ingredients. The system acts as a tool: The output should suggest changes that involve substituting ingredients from your list of favorite meals into your current meal. It should suggest no more than 2 substitutions. The substitutions may range from small variations (eg add pepper flakes) to total change of key ingredients.

## Style Guidelines:

- Primary color: A warm coral (#FF7F50) to evoke a sense of appetite and comfort.
- Background color: Light cream (#F5F5DC), almost white, to ensure readability and a clean look.
- Accent color: A muted olive green (#808000) for secondary actions and highlights, contrasting the primary color.
- Headline font: 'Belleza' (humanist sans-serif) for a fashionable, art-aligned look. Body font: 'Alegreya' (humanist serif) to be paired with Belleza.
- Use food-related icons to represent different cuisines or meal types.
- A clean, card-based layout for easy meal selection and day assignment.
- Smooth transitions when adding or reordering meals in the planner.
